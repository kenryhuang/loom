# Action 效用评价

## 目标与边界

保留现有 execution flow 的阶段、Working／tool 行和精确成本账本。在每个 action 上增加语义效用，
回答它贡献了什么、是否有增量、当时是否值得执行。工具成功不等于有价值；最终通过验收也不能反推每一步必要。
失败的试验、排除假设、发现约束和必要的复验可以有正向价值。评价以当时可用的信息解释必要性，
用后续制品、公开决定和验收记录追踪实际贡献，明确区分事前判断和事后关联。

## 契约

- 必要性：necessary / supporting / avoidable / unknown。
- 结果贡献：decisive / material / limited / none / negative / unknown。
- 增量：new / refinement / revalidation / duplicate / unknown。
- 贡献类型：evidence / root_cause / artifact / verification / decision / delivery / overhead / unknown。
- 记录新增的信息或制品变化、评价理由、移除该动作的可能影响、可验证的改进建议及 confidence。
- 分别引用自身动作证据、后续贡献证据、先前比较动作及验收条件／结果。引用来自固定 run 的已交付证据页。
- 高价值判断需要结果贡献引用；重复判断需要较早动作的比较引用。宿主校验 ID、引用来源与时间顺序，
  语义关联仍是 evaluator 的推断，不因为引用合法就成为确定因果。
- 模型 action 评价公开的计划、判断、工具选择、报告和后续验证效果，不读取隐藏 reasoning。
  同一结果可以关联模型和工具，成本仍各自只记一次，不把相关耗时当作可节省耗时。

## 事实与语义分工

宿主计算同工具、相同规范化输入的先前调用，以及记录输出是否完全相同。输出不同时不自动判定有新价值，
输出相同时也不自动判定浪费。框架不能证明环境未变化时，必须考虑复验、外部状态和失败重试。
输入、输出引用、阶段、有效目标修订、制品和 acceptance 事件一起交给 evaluator。

## 执行与预算

新增 utility 阶段，位于结构协调之后、目标级诊断之前。每批最多4个 action，按目标修订隔离；
有界证据窗口优先覆盖目标动作、相同输入的先前动作、相邻后续结果和验收／最终交付。
所有删减以候选页数、已交付页数和 partial 标记表达，不把未送达证据当作不存在。
结果允许 unknown，也允许明确显示未评估；不会因缺少一个判断反复整段重跑。
按批保存并复用现有总调用、tokens、时间预算；大请求先拆 action 批次，再拆证据页。
诊断复用已保存效用判断，避免重复开展另一套逐 action 评价。

分析器／prompt 升级到 v3，兼容读取历史报告。旧 v2 中断作业保留已验证结构，补跑效用与后续诊断；
已完成旧报告显示未评估，必须新运行 Deep evaluation 才能获得新判断，不在浏览时偷偷调用模型。

## 页面

原有 action 表增加紧凑的效用列；展开行内展示三个维度、增量说明、贡献／比较／验收证据和改进建议。
顶部显示已评估覆盖率与价值分布。未评估与“已评估但证据不足”分别呈现，不生成虚假的0分或统一总分。
保留现有图、时间、TTFT、TPS和报告入口。

## 验证

覆盖无效／跨 run 引用、未来比较、缺少贡献引用、重复读与合理复验、模型公开输出、
预算中断恢复、旧版本升级、只读历史投影、UI展开折叠和证据跳转。
以固定来源的事实和可控 evaluator 测试验证协议；真实判断质量需要后续实际报告复核。

## 执行流程分类修正（execution view v6）

流程图复用 trace kernel 的调用关联：原生 tool-call ID、显式父调用、Managed JSON action ID，
以及有唯一身份依据的恢复调用。不按事件相邻关系推测调用者，重复或冲突身份保留未关联。
因此 JSON action 模式下的 Working 耗时也归入其实际发起的操作，包括生成最终报告。

分类优先采用工具身份及完整命令的保守规则，支持只读命令串联与有限的文件遍历循环；
不能用页面截断的命令预览进行判断。无法直接分类时，依次使用已有逐 action 评估、
明确关联该调用且引用其原始事件的阶段评估。阶段时间窗口本身不构成归类依据。
仍无判断的脚本，可使用与实际工具和参数一致的 JSON action 中明确声明的验证用途；
不依据脚本文件名或隐藏 reasoning 推断。没有充分依据或判断冲突时继续显示 Other。

语义评估和声明用途均标注为 inferred purpose，展开可查看理由与原始证据；
“用于验证”不代表验证成功、充分或已通过 acceptance。旧报告读取时自动重建展示，
保留原始报告、成本归属和时间统计，不额外调用 evaluator。
